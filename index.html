Install

From download to sign-in in minutes.

CoolCloud runs on a small server, a NAS, a VPS or a spare computer. Node 24 and SQLite are the only hard requirements.

1

Get the Community edition

Clone the repository (or download the ZIP) anywhere on the machine that will host it.

2

Run the installer

node bin/coolcloud.js --install asks for a location, organization, admin account and port, then prepares the instance.

3

Start it

node bin/coolcloud.js --start (or npm start) serves the interface at http://localhost:8080.

4

Put it online, safely

Add a domain, TLS and a reverse proxy using the hosting guide. Then enable CC Defender on Enterprise for network policy.

Terminal
# 1 · get the code
$ git clone https://github.com/openhcat/CoolCloud-Community.git
$ cd CoolCloud-Community

# 2 · create your instance
$ node bin/coolcloud.js --install

# 3 · start the server
$ node bin/coolcloud.js --start

What you need

  • Node.js 24 or newer
  • Any OS that runs Node — Linux, macOS, Windows
  • Optional: Docker for the Collabora Office container
  • Optional: a domain and reverse proxy for HTTPS

Guides

Hosting, TLS, backups, the CLI and the app manifest format live in the documentation folder. Enterprise deployment help comes with the licence.
